# katlyn-hobbs.github.io

Personal website of Katlyn L. Hobbs, hosted with GitHub Pages at https://katlyn-hobbs.github.io/

Plain HTML and CSS, no build step:

- `index.html` – About
- `research.html` – Research
- `publications.html` – Publications
- `cv.html` – CV page (embeds `cv/Hobbs_CV.pdf`; replace that file to update the CV)
- `css/style.css` – all styling
- `images/` – photo and animations

The header, profile sidebar and footer are repeated in each page, so change all four if you edit them.
